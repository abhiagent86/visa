# Visa CEMEA: a sales operations perspective

Single-page site (`index.html`, no build step) covering:

1. Best-in-class B2B sales operations vision: the operations engine, the customer value journey, core metrics, quota and incentives, operating mechanics
2. AI and automation potential: two lenses, priority use cases, how to build one, AI impact maps (account planning, pipeline management, forecasting), measurement, roadmap, agentic commerce
3. Understanding of Visa and recommendations for CEMEA, with questions to explore
4. The value-added services business: market opportunity, solutions, selling motion, Visa vs competition, recommendations and a VAS scorecard

## Edit the page in your browser

1. Open the page with `?edit` added to the address, e.g. `https://<your-username>.github.io/<repo-name>/?edit`. Visitors without `?edit` never see the editor.
2. Click **Edit text**, then click any text to change it. Each section gets **Move up**, **Move down**, **Add text block** and **Delete section**. **Add section** adds a new section and its menu link.
3. Edits save automatically, but only in your browser. To publish them, click **Download HTML** and upload the downloaded `index.html` to the repo, replacing the old one.
4. **Reset** discards your saved browser edits and shows the published page again.

## Publish with GitHub Pages

1. Put `index.html` at the root of the repository's `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. The site appears at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

GitHub Pages sites are public, even when the repository is private (on paid plans). Share the link only with people you intend to.
